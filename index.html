About

A short introduction

I'm a software engineer at BeamNG GmbH, working on BeamNG.tech — the company's engineering simulation platform for autonomous driving and ADAS development. I integrate the simulator with ROS/ROS2, MATLAB and Simulink, build the API bridges that make real-time automation possible, and QA across C++, Python and Lua.

Before BeamNG I built autonomous delivery and navigation systems on robotics teams in Malaysia and Singapore, after graduating in Mechatronics Engineering. I'm based in Istanbul, Turkey, and I'm always up for anything involving robotics, simulation or automation.

What I work on

Where the simulator meets robotics and autonomy toolchains

  • Simulation integration — Connecting BeamNG.tech with ROS/ROS2, MATLAB and Simulink so high-fidelity vehicle simulation can drive ADAS and autonomous-driving workflows.
  • API bridges — The interfaces that make real-time automation, data acquisition and external robotics toolchains possible.
  • Automated QA — Integration and regression testing across C++, Python and Lua, from bug reproduction to root-cause analysis.
  • B2B technical work — Customer-facing integration, technical documentation and support for teams building on the platform.
